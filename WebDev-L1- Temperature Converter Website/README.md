# 🌡️ Temperature Converter

A modern and responsive **Temperature Converter Website** built using **HTML, CSS, and Vanilla JavaScript**.

This project allows users to quickly convert temperatures between **Celsius, Fahrenheit, and Kelvin** with a clean, interactive, and visually appealing interface.

---

## 🚀 Live Features

- 🌡️ Convert between Celsius, Fahrenheit, and Kelvin
- ⚡ Instant temperature conversion
- 🎨 Modern neon/glowing user interface
- 📱 Fully responsive design
- ✅ Input validation
- 🔄 Easy unit selection
- 📊 Displays conversion results for all three units
- 🧮 Shows the conversion formula
- ✨ Interactive buttons and animations
- ❌ Handles invalid and empty inputs

---

## 🛠️ Technologies Used

### HTML5

Used to create the structure and content of the temperature converter.

### CSS3

Used for:

- Responsive layout
- Neon/glowing effects
- Gradients
- Animations
- Cards and buttons
- Modern UI styling

### JavaScript

Used to:

- Read user input
- Detect the selected temperature unit
- Perform temperature calculations
- Validate input
- Dynamically update conversion results
- Display conversion formulas
- Handle user interactions
