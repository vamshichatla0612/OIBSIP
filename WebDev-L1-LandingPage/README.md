# 🚀 NOVA – Productivity Landing Page

A modern and responsive productivity landing page created as part of my
Oasis Infobyte Web Development Internship – Level 1 Task 1.

NOVA is designed as a productivity-focused website that provides users with
a clean and interactive interface for managing their daily activities,
tasks, reminders, and productivity goals.

---

## 📌 Project Overview

NOVA is a modern productivity website built with HTML, CSS, and JavaScript.

The project focuses on creating a professional landing page with:

- Modern user interface
- Responsive design
- Navigation bar
- Hero section
- Call-to-action buttons
- Productivity-focused sections
- Login and Signup pages
- Dashboard interface
- Interactive JavaScript features
- Mobile-friendly layout

---

## 🎯 Objective

The main objective of this project is to practice frontend web development
and create a responsive and visually appealing landing page.

This project was developed as part of:

**Oasis Infobyte Web Development Internship – Level 1**

**Task 1 – Landing Page**
